# Gestión de Riesgos

Se realizó una identificación y evaluación de riesgos asociados al producto y al proyecto, considerando aspectos **técnicos, de producto, personas, proyecto, organizacionales y externos**.

Los riesgos fueron evaluados según probabilidad, impacto y exposición, definiendo acciones de mitigación, contingencia y seguimiento.

Algunos riesgos tuvieron impacto directo sobre QA, principalmente aquellos relacionados con:

* Cobertura insuficiente de pruebas.
* Errores en funcionalidades críticas.
* Rendimiento.
* Integración Backend/BD.
* Restricciones de tiempo para la ejecución.
